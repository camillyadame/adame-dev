# Adame.dev — revisão final

## Ajustes desta versão
- Hero simplificado: removidos elementos decorativos redundantes e reduzida a altura da seção.
- Mantida a ilustração em código da tela + celular, com assinatura `a._` (ponto rosa, cursor verde).
- Seção Diferencial reescrita para não repetir o processo de trabalho.
- Novo diferencial oficial: Kit do projeto + treinamento.
- Observação clara de que manutenção/suporte contínuo são combinados separadamente.
- Espaçamento vertical reduzido nas principais seções para uma landing mais objetiva e fluida.
- Processo preservado como seção específica de "Como funciona".

## Validação local
Rode `npm install`, `npm run build` e `npm run dev` antes do deploy. A instalação de dependências no ambiente de geração excedeu o limite de execução, portanto o build final deve ser confirmado localmente.
